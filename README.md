# 호우 대응 브리핑 — 첫 번째 산출물

제공된 가상 보도자료 3건을 검색하는 빌드 과정 없는 정적 웹 페이지입니다.

- `index.html`: 페이지 구조
- `styles.css`: 반응형 스타일
- `app.js`: JSON 로딩, 부처·본문 검색, 결과 건수, 원문 모달, 수치 비교표
- `data/보도자료데이터.json`: 제공된 원본 JSON 그대로 복사
- `data/3개_보도자료_묶음.md`: 제공된 원문 묶음 그대로 복사

## 실행

이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다. JSON을 fetch하므로 HTML 파일을 더블클릭하는 file:// 방식 대신 HTTP 서버로 열어야 합니다.

GitHub Pages는 기본 브랜치의 루트(`/`)를 게시하도록 설정합니다. `.nojekyll` 파일로 정적 파일을 그대로 제공합니다. 별도 패키지 설치, 서버, API 키가 필요하지 않습니다. 상대 경로를 사용해 GitHub Pages의 저장소 하위 경로에서도 JSON과 자산을 불러옵니다.

## 검색 규칙

기본 검색은 `부처` 또는 `본문`에 입력한 문구가 포함되는지 확인합니다. 검색 범위를 `부처` 또는 `본문`으로 한정할 수 있고 부처 버튼도 함께 적용할 수 있습니다. 빈 검색어는 선택한 부처의 전체 자료를 표시합니다. 결과 건수는 실제 필터 결과의 길이로 갱신합니다. 제목은 별도 검색 필드가 아니지만 제공된 JSON의 본문 첫 줄에도 같은 제목이 포함되어 있습니다.

## 외부 리소스

외부 이미지가 `images.unsplash.com`에서 직접 로드됩니다. Syuhei Inoue의 빗방울 참고 이미지이며 출처 링크를 페이지에 표시했습니다. 해당 이미지는 보도자료의 현장 사진이 아닙니다.

출처: https://unsplash.com/photos/water-droplets-on-glass-window-SsfPA_sZ4Wk

본문의 모든 사실과 수치는 제공된 두 파일만 사용했습니다. 서로 다른 집계값을 임의로 통일하거나 합산하지 않았습니다. 기상청의 중대본 지원 시각(16:40)과 호우주의보 발효 시작 시각(11:00)을 구분했습니다. 참고 법령·통계·타부처 매뉴얼·언론 클리핑은 사용하지 않았습니다.

## 사용성

모바일 화면, 키보드 검색, 검색 결과 알림, 모달 Esc 닫기, 빈 결과, JSON 로딩 실패·재시도, 외부 이미지 로딩 실패 안내를 지원합니다. 사용자 입력과 JSON 내용은 HTML로 해석하지 않고 텍스트 노드로 표시합니다.
